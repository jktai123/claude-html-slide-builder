```markdown
# 📄 AI簡報工具攻略：深度摘要

### 1. 文獻概覽
- **標題**：AI簡報工具攻略：NotebookLM、Claude···20篇實測教學，提示詞、修改技巧一次打包
- **來源**：《數位時代》專題 (Topic 983)
- **連結**：https://www.bnext.com.tw/topic/view/983

### 2. 邏輯架構
- **背景動機**：在 AI 簡報工具爆發的時代，工作者常面臨「工具選型混亂」以及「因為指令空泛導致版面失控、陷入修改地獄」的痛點。
- **關鍵論點**：
  1. **工具三分類**：將工具定位為「快速視覺型 (如 Gamma)」、「原生編輯型 (如 Claude, Gemini)」與「整合平台型 (如 Canva)」，依場景選型是第一步。
  2. **提示詞兩大原則**：指定精確頁數與框架、給予結構化大綱，避開空泛指令。
  3. **協作工作流**：建立「選型 ➔ 結構化 Prompt ➔ 原生後製精修」的三階段閉環工作流。
- **實測重點**：
  - **ChatGPT (Images 2.0)**：具備高中文準確度、風格一致性，支援打包匯出。
  - **Claude Design**：適合規劃簡報架構並匯出至外部平台。
  - **NotebookLM**：整理文獻脈絡，避免指令模糊導致失控。

### 3. 展望啟示
- **限制**：AI 生成的簡報多數缺乏深度品牌客製化，後製修改仍是不可或缺的環節。
- **產業影響**：簡報製作模式正從「手動排版」轉變為「AI 負責初稿、人負責總監把關與細修」的協作時代。
```

### 🧑🏫 [3] 教學講義條列版

```markdown
# 🧑🏫 講師備課筆記：AI 簡報大師工作流

### 1. 課程主題與學習目標
- **課程主題**：AI 簡報工具選型與提示詞實戰
- **學習目標**：能依場景精準選用工具、學會結構化 Prompt，並掌握快速後製技巧，避開簡報修改地獄。

### 2. 核心觀念速讀版
- **定位優先**：簡報的速度與可編輯性通常是互斥的，先確定是否需要精修再選工具。
- **結構提示**：AI 需要明確的軌道，必須給予「背景、受眾、大綱、風格」的結構化指示。
- **把關思維**：AI 負責完成 70% 的初稿，人類則扮演設計總監，進行最後 30% 的文字與版面精修。

### 3. 重點名詞清單
- **`.pptx`**：PowerPoint 原生簡報格式，具備最高的本地可編輯性。
- **`Bento Grid (邊界網格)`**：一種高密度、結構清晰的卡片排版方式，適合呈現工具概覽。
- **`GPT Images 2.0`**：ChatGPT 內建的生圖模型，適合生成風格高度一致的投影片配圖。

### 4. 教學提醒
- ⚠️ **易混淆概念**：以為提示詞寫得越長、AI 就做得越好（實際上結構混亂反而容易讓 AI 離題）。
- ❌ **常見誤解**：以為 AI 能一步到位直接生成不需要修改的完美 PPT。
- 🎯 **教學比喻**：AI 就像一個剛進簡報設計公司的實習生，你需要給他明確的「格式規格書」（提示詞模板）他才能交出合格的草稿。

### 5. 延伸思考題
- Q1：當你需要一份「5分鐘後就要上台」且不需要複雜修改的報告簡報，你會選擇 Gamma 還是 Claude？為什麼？
- Q2：在簡報生成過程中，如果 AI 出現了嚴重的排版跑版，你認為「修改提示詞重新生成」與「匯出後手動拉框」哪一個效率更高？
```
