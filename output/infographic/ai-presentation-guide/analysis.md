# Content Analysis: AI Presentation Tool Guide

- **Topic**: AI簡報工具攻略：從選型、提示詞設計到後製修改的完整工作流
- **Target Audience**: 辦公室白領、工程師、PM、設計師等需要頻繁製作簡報的專業人士
- **Content Complexity**: 中高。包含 4 種主要 AI 簡報工具分類、核心實測重點與 3 階段簡報工作流。
- **Core Insights**:
  1. **工具選型**：
     - 快速視覺輸出型：NotebookLM、Gamma (適合快速產出，修改要求低)
     - 可編輯原生 PPT 型：Claude Cowork/Design、Google + Gemini (適合後續微調)
     - 整合平台型：Canva + GPT/Claude、PowerPoint + Claude (熟悉的工作環境，學習成本低)
  2. **實測與最佳實踐**：
     - ChatGPT (GPT Images 2.0)：中文生成準確度高，風格一致性強，支持打包 PPTX。
     - Claude Design：建立專案到匯出 PPTX/Canva。
     - NotebookLM/Gamma：避開模糊 NG 指令，使用「2 大原則 + 1 組提示詞」控制版面。
  3. **工作流建議**：
     - 「選工具」 -> 「下提示詞」 -> 「後製修改」三個階段。
- **Tone**: 專業、實用、極簡、邏輯嚴密
- **Design Instructions**: Notion-style layout (Bento grid, clean outlines, grayscale palette with black/gray/white, minimal line-art icons, sans-serif fonts, ample whitespace, high-density structured box layout).
